# 小红书写作风格指南 v1

> 基于 xhs-content-architecture.md 提取，供初稿写作者参考。

---

## 一、标题规范

- **字数**：≤20中文字
- **公式**：人群 + 痛点/场景 + 数字/结果
- **常用类型**：避坑型、清单型、反常识型、场景型、情绪型、对比型
- **核心词前置**：标题前15字必须包含领域核心关键词

### 各领域标题示例
| 领域 | 示例 |
|------|------|
| 📅 老黄历 | 老黄历不是迷信，是古人的生活节奏表 |
| 🫁 哮喘 | 咳嗽超过8周，别只当感冒 |
| 🤖 AI | 周鸿祎最近讲AI，我整理出5个普通人机会 |
| 🧠 Agent | 普通人学Agent，先别碰复杂代码 |
| 🔒 安全 | 入住酒店后，先做这5个防偷拍检查 |
| 🔮 玄学 | 九字真言不是玄学，更像一种专注练习 |

---

## 二、正文规范

- **字数**：500-800字（上限1000字符）
- **结构**：
  1. 首句直接砸痛点，不铺垫
  2. 2-3句背景说明
  3. N个要点，每点1-2句
  4. 一句话总结
  5. 互动问题（低门槛，选择题型）
  6. 合规声明（如需）
- **分段**：用 emoji 分隔，不要纯文字大段
- **SEO**：正文前2行自然重复核心词

---

## 三、图文卡片（7页结构）

| 页 | 内容 | 设计要点 |
|----|------|---------|
| P1 封面 | 大字痛点标题 8-14字 | 强场景 + 情绪底色 |
| P2 结论 | 一句话说清解决什么 | 预告干货 |
| P3 背景 | 为什么重要 | 数据/案例 |
| P4 方法1-2 | 具体步骤 | 清单/图表 |
| P5 方法3-4 | 具体步骤 | 清单/图表 |
| P6 避坑 | 常见误区 | 红框警示 |
| P7 总结 | 复盘 + 互动引导 | "下篇想看XX的扣1" |

**核心原则**：正文做SEO+互动，图片放知识+干货。

---

## 四、互动模板（ABC型）

```
🎣 选择型: "你想看 A.XXX 还是 B.XXX？"
🎣 投票型: "想看XX的扣1，想看YY的扣2"
🎣 提问型: "你们公司接大模型了吗？评论区聊聊"
🎣 体验型: "你是夜咳多，还是白天咳多？"
🎣 系列型: "下篇讲XX，你有踩过什么坑？"
```

> 不要问宏大问题（"你怎么看AI的未来？"），设定低回答门槛。

---

## 五、合规红线

### 医疗类（哮喘/CVA）
- ❌ 禁止：治愈、根治、停药、不用去医院、偏方
- ✅ 可以：科普整理、就医准备、指南白话解读
- 📝 必须加声明：本文仅作健康科普，不替代医生诊断和治疗。

### 安全类（反诈/防偷拍）
- ❌ 禁止：具体入侵步骤、漏洞利用代码
- ✅ 可以：安全意识提醒、自查清单

### 玄学类（小六壬/九字真言）
- ❌ 禁止：一定发财、改命、保证转运、消灾治病
- ✅ 可以：传统文化、民俗美学、心理暗示、每日仪式感
- 📝 包装为：今日自省关键词、今日行动建议

### 通用红线
- ❌ 极限词：最、第一、绝对、100%
- ❌ 二维码/微信号/外链
- ❌ 搬运/洗稿

---

## 六、信源分层（SABC）

- **B/C层**：找选题和痛点（小红书热帖、评论区、贴吧）
- **S/A层**：做论据和权威背书（指南、论文、三甲医生）

写稿时标注信息来源层级，优先使用S/A级信源。

---

## 七、话题标签

- 数量：3-5个
- 组合：1大热 + 2精准 + 1场景
- 示例：#老黄历 #传统色 #新中式生活 #每日仪式感

---

## 八、发布后规范

- 黄金1小时在线回复评论
- 不改正文（错字在评论区更正）
- 发完去同领域点赞评论他人（增加活跃度）
