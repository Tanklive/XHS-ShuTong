# 每日XHS内容生成规则 v1.0

> 固化规则，每次生成XHS内容前必须对照执行。

## 内容结构（策略B：单号轮作）

```
📅 老黄历（2句话）
  → 第1句：日期+宜忌
  → 第2句：今日行动建议

🫁🤖🧠🔒🔮 5个领域
  → 每天随机抽1个深度领域：3-4句（含机制/数据/案例）
  → 其余4个领域：各1句话带过

#标签（≤5个）
  → 公式：1大热 + 2精准 + 1场景

正文 ≤1000字（含标签）
```

## 标题规则

- ≤20字
- 公式：`人群标签 + 数字量化 + 情绪钩子`
- 类型：避坑型/清单型/反常识型/场景型/情绪型/对比型

## 5张知识卡片结构（v2：AI生图+文字叠层）

| 序号 | 类型 | 用途 | 生成方式 |
|------|------|------|----------|
| P1 | 封面图 | AI生成封面背景+大字标题 | AI生图（硅基/即梦/可灵轮换） |
| P2 | 知识卡 | 核心知识点/数据可视化 | AI生图+文字叠层 |
| P3 | 方法卡 | 步骤/操作路径 | AI生图+文字叠层 |

### AI 生图平台轮换策略
- 硅基流动：100张/月（主力）
- 即梦：按量计费（测试用）
- 可灵：按量计费（测试用）
- 每天3张，月均90张，硅基流动免费额度够用

### 生成流程
```bash
# 1. AI生成背景图
python3.13 scripts/ai_image_gen.py --prompt "<描述>" --size 768x1024 --save /tmp/xhs_bg_1.jpg

# 2. Pillow叠文字（保留现有xhs_cards.py的文字叠层能力）
# 或直接用 HTML/CSS + Playwright 截图（方案B升级后）
```

## 发布流程

```
① 读取 daily-xhs-raw.md（已有今日素材）
② 按结构组装：老黄历 + 深度领域 + 4个1句 + 标题 + 标签
③ 正文 ≤1000字
④ 生成5张知识卡片（xhs_cards.py）
⑤ 和吉量确认内容质量
⑥ 推给大哥预览
⑦ 大哥确认后发布
⑧ 归档+清理（xhs_archive_cleanup.py）：
   - 图片+正文 → ~/shared/xhs-publish-records/YYYY-MM-DD/
   - 清空 /tmp/xhs_card_*.jpg
   - 防止第二天残留历史图
```

## 禁令

- ❌ 来源链接 / 参考标注
- ❌ 数据采集时间尾注 / 技术说明
- ❌ 今日小结段落
- ❌ 文件头 / 参数区块（正文纯净）
- ❌ 极限词（最、第一、绝对、100%）
- ❌ 二维码/微信号/外链/公众号名称

## 合规声明

- 医疗类：本文仅作健康科普，不替代医生诊断和治疗
- 安全类：不提供可被滥用的攻击教程
- 玄学类：传统文化/民俗美学/心理暗示，不保证转运

## SEO关键词

- 标题前15字：核心词必放
- 正文前2行：自然重复核心词
- 图片文字：每页出现相关词
- 话题标签：3-5个
