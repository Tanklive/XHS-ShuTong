# ⚠️ 重大架构调整：一个号不能发6类

## 问题诊断

小红书推荐系统通过**谁点开、谁收藏、谁评论**判断账号标签。当前每日一篇含6个方向，吸引的人群差异巨大：
- 新中式用户 ← → AI工程师 ← → 哮喘患者 ← → 安全从业人员

系统无法判断该推给谁 → **账号垂直度归零 → 推荐量越来越低**。

## 三级策略

### 策略A：单号聚焦（推荐起步）
选一个主赛道，前30篇死磕，不跨领域。

### 策略B：单号轮作（当前可用）
每天只发**1个深度领域**，6天一轮。标题和封面始终围绕该领域。

### 策略C：多号矩阵（终极目标）
3个账号分别运营：
| 账号 | 方向 | 赛道人设 |
|------|------|---------|
| 号1 | 📅 老黄历 + 🔮 小六壬 | 新中式生活/赛博玄学 |
| 号2 | 🫁 哮喘/CVA | 呼吸健康科普 |
| 号3 | 🤖 AI + 🧠 Agent + 🔒 安全 | AI效率/AI安全 |

## 当前采用：策略B（单号轮作）

# 第二篇：单条笔记结构（卡片化）

> 核心理念：**正文短（500-800字），信息放图里。正文负责SEO和互动，图片负责知识和收藏。**

## 7页图文结构（推荐）

| 页 | 内容 | 设计要点 |
|----|------|---------|
| P1 封面 | 大字痛点标题 8-14字 | 强场景 + 情绪底色 + 箭头/贴纸 |
| P2 结论 | 一句话说清楚这篇解决什么 | 预告后续干货 |
| P3 背景 | 为什么这个问题重要 | 数据/案例/场景 |
| P4 方法1-2 | 具体步骤 | 清单/图表 |
| P5 方法3-4 | 具体步骤 | 清单/图表 |
| P6 避坑 | 常见误区/注意事项 | 红框警示 |
| P7 总结 | 一句话复盘 + 互动引导 | "下篇想看XX的扣1" |

## 图片用途声明（重要）

> 大哥指定图片数量时，每张图有明确用途，不是"生成一堆再截断"。

**标准5张结构**：
| 序号 | 用途 | 说明 |
|------|------|------|
| 第1张 | 封面图 | 大字标题，吸引点击（xhs_cover_gen.py 生成） |
| 第2张 | 知识卡片1 | 核心知识点/数据 |
| 第3张 | 知识卡片2 | 方法/步骤清单 |
| 第4张 | 避坑卡片 | 常见误区/注意事项 |
| 第5张 | 互动引导 | 总结+关注引导 |

**原则**：
1. 数量由大哥定，不是由生成逻辑定
2. 每张图有用途标签，不随机截断
3. 上传前打印清单确认
4. 数量不对就停下来问，不静默处理

## 1000字正文模板

```markdown
标题：{人群+痛点+结果，≤20字}

正文：
{首句：直接砸痛点，不铺垫}

{2-3句背景说明}

{N个要点，每点1-2句}

{一句话总结}

{互动问题}

{合规声明（如需）}
```

## 图片 vs 正文分工

| 放哪里 | 内容类型 |
|--------|---------|
| 正文 | 关键词SEO + 简短解释 + 互动问题 + 合规声明 |
| 图片 | 步骤清单 + 对比表 + 路线图 + 误区总结 |
| 评论区 | 参考来源 + 延伸阅读 + 模板链接 |

# 第三篇：合规红线

## 医疗类（🫁 哮喘/CVA）
```
❌ 不能说：治愈、根治、停药、不用去医院、这个药最有效、偏方
✅ 可以说：科普整理、就医准备、医生观点整理、指南白话解读
📝 必须加：本文仅作健康科普，不替代医生诊断和治疗。如有持续咳嗽、喘息、胸闷等症状，请及时就医。
```

## 安全类（🔒 反诈/防偷拍/隐私）
```
❌ 不能说：具体入侵步骤、漏洞利用代码、绕过系统方法
✅ 可以说：安全意识提醒、官方指南白话版、自查清单
📝 注意：不提供可被滥用的攻击教程
```

## 玄学类（🔮 小六壬/九字真言）
```
❌ 不能说：一定发财、一定复合、算准你的命、改命、保证转运、消灾治病
✅ 可以说：传统文化、民俗美学、心理暗示、情绪疗愈、每日仪式感、古籍词句赏析
📝 包装：今日自省关键词、今日行动建议、今日情绪提醒
```

## 通用红线
```
❌ 极限词：最、第一、绝对、100%
❌ 二维码/微信号/外链/公众号名称
❌ 搬运/洗稿（系统查重）
❌ 互赞互粉群（无效社交 → 权重归零）
❌ 买赞买粉（反作弊 → 废号）
❌ 发布后反复修改正文
```

# 第六篇：互动设计与流量运营

## ABC互动模板（低门槛评论）

```
🎣 选择型: "你想看 A.XXX 还是 B.XXX？"
🎣 投票型: "想看XX的扣1，想看YY的扣2"
🎣 提问型: "你们公司接大模型了吗？评论区聊聊"
🎣 体验型: "你是夜咳多，还是白天咳多？"
🎣 纠错型: 留一个无关紧要的小瑕疵（非关键信息），激发纠正欲
🎣 系列型: "下篇讲XX，你有踩过什么坑？我先记下来"
```

> ⚠️ 不要问太宏大的问题（"你怎么看AI的未来？"），设定低回答门槛。

# 第七篇：复盘与迭代

## 24h后看数据

| 信号 | 问题 | 改法 |
|------|------|------|
| 曝光高 点击低 | 封面/标题不行 | 换大字报风格 |
| 点击高 读完低 | 开头啰嗦 | 第一句直接砸痛点 |
| 阅读高 互动低 | 像说明书 | 加个人体验 + 提问 |
| 收藏高 评论低 | 工具属性强 | 结尾加开放式提问 |

## 每日30分钟流程

```
① 看热点（10min）
  每个方向看5-10条：小红书搜索→热门→标题→评论

② 记录痛点（5min）
  用户在担心什么？问什么？争论什么？收藏什么？

③ 找权威来源（5min）
  用 S/A 层信源验证观点（只看权威，不看博主二手转述）

④ 写成图文（10min）
  痛点标题 → 结论先行 → 3-5要点 → 1个清单 → 1个互动问题
```
